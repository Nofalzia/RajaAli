# Raja Ali Portfolio

**Live demo:** [https://rajaali.netlify.app](https://rajaali.netlify.app)

## What it does
A high-performance, visually immersive portfolio website designed for a professional filmmaker and content creator. The site provides a cinematic experience to showcase high-quality video work and photography while maintaining fast load times through advanced media optimization.

## Tech stack
- **Frontend:** HTML5, Vanilla JavaScript
- **Styling:** CSS3, SCSS (Sass)
- **Deployment:** Netlify
- **Analytics:** Statcounter

## Key features
- **Optimized Media Delivery:** Custom lazy-loading logic and responsive source sets (`srcset`) to handle heavy 4K video and high-resolution stills efficiently.
- **Immersive Video Experience:** Responsive full-bleed background videos and interactive modal-based video popups for high-quality playback.
- **Custom Branded Preloader:** An engaging, dynamic loading screen designed to manage user expectations while heavy assets are fetched.
- **Minimalist UX:** A "content-first" design philosophy that eliminates fluff to ensure the filmmaker's work remains the focal point.
- **Responsive Stills Gallery:** An adaptive photo grid that gracefully scales between desktop and mobile views.
